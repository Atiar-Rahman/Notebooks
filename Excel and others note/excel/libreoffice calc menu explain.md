
অবশ্যই। আমরা **LibreOffice Calc-এর Menu Bar একদম beginner level থেকে** শিখতে পারি। আপনি যেহেতু spreadsheet শিখছেন, আমি প্রতিটি menu-তে **কোন option কী কাজ করে + কখন ব্যবহার করবেন**—এভাবে বুঝাব।

আজ শুরু করি **File Menu** দিয়ে।

# 📁 File Menu — কী কাজে লাগে?

**File Menu** মূলত workbook/file-এর সাথে সম্পর্কিত কাজের জন্য। যেমন **নতুন file তৈরি, open, save, print, export, close** ইত্যাদি।

---

## 1. New

**File → New**

নতুন document তৈরি করতে ব্যবহার হয়।

Calc-এ নতুন spreadsheet:

**File → New → Spreadsheet**

Shortcut:

```text
Ctrl + N
```

### কখন ব্যবহার করবেন?

নতুন Excel/Calc file শুরু করতে।

---

## 2. Open

**File → Open**

আগে থেকে থাকা কোনো spreadsheet খুলতে।

Shortcut:

```text
Ctrl + O
```

যেমন:

```text
sales.xlsx
student.ods
report.xlsx
```

এগুলো খুলতে পারবেন।

---

## 3. Recent Documents

আপনি সম্প্রতি যেসব file খুলেছেন সেগুলোর list দেখাবে।

যেমন:

```text
sales.xlsx
student.xlsx
report.ods
```

বারবার একই file খোলার জন্য সুবিধাজনক।

---

# 💾 4. Save

**File → Save**

আপনার বর্তমান কাজ save করবে।

Shortcut:

```text
Ctrl + S
```

### উদাহরণ

আপনি Sheet1-এ data দিলেন:

```text
Product    Price
Laptop     40000
Mouse      1000
```

তারপর:

```text
Ctrl + S
```

চাপলে file-এ changes save হবে।

---

# 💾 5. Save As

**File → Save As**

এটা খুব গুরুত্বপূর্ণ।

আপনি একই file-কে **অন্য নাম বা অন্য format-এ** save করতে পারবেন।

Shortcut:

```text
Ctrl + Shift + S
```

উদাহরণ:

বর্তমান file:

```text
sales.ods
```

আপনি চাইলে Save As করে:

```text
sales.xlsx
```

করতে পারেন।

### Save বনাম Save As

**Save:**

> বর্তমান file-এর পরিবর্তন save করে।

**Save As:**

> নতুন নাম/location/format দিয়ে আলাদা করে save করতে পারে।

---

# 📤 6. Export

**File → Export**

Document-কে অন্য format-এ বের করার জন্য।

বিশেষ করে:

```text
PDF
```

তৈরি করতে কাজে লাগে।

উদাহরণ:

আপনার Sheet3-এ সুন্দর report আছে।

তখন PDF বানিয়ে কাউকে দিতে পারেন।

---

# 📄 7. Export as PDF

আপনার spreadsheet-কে PDF বানাবে।

উদাহরণ:

```text
Sales_Report.ods
        ↓
Sales_Report.pdf
```

PDF করলে অন্য computer/mobile-এও সহজে দেখা যায়।

---

# 🖨️ 8. Print

**File → Print**

Spreadsheet কাগজে print করার জন্য।

Shortcut:

```text
Ctrl + P
```

এখান থেকে ঠিক করতে পারবেন:

* কোন page print হবে
* কতগুলো copy
* portrait/landscape
* paper size
* কোন cells/page range print হবে

---

# 👀 9. Print Preview

Print করার আগে দেখতে পারবেন **কাগজে আসলে কেমন দেখাবে**।

এটা খুব useful।

কারণ spreadsheet screen-এ সুন্দর দেখালেও print করলে কখনো:

```text
Column A B C D
```

এক page-এ না-ও ধরতে পারে।

তাই print করার আগে Preview দেখা ভালো।

---

# 📑 10. Properties

File সম্পর্কে information দেখায়।

যেমন:

* File name
* File size
* Created/modified information
* Document properties

সাধারণ spreadsheet কাজের সময় এটা খুব বেশি লাগবে না।

---

# 🔒 11. Digital Signatures

Document-এর digital signature সংক্রান্ত কাজ।

সাধারণ beginner spreadsheet কাজের জন্য **এটা এখন বাদ দিতে পারেন**।

---

# 🧹 12. Close

বর্তমান spreadsheet বন্ধ করবে।

Shortcut:

```text
Ctrl + W
```

যদি save না করা changes থাকে, Calc জিজ্ঞেস করবে save করবেন কি না।

---

# 🚪 13. Exit LibreOffice

পুরো LibreOffice application বন্ধ করবে।

অর্থাৎ শুধু একটা spreadsheet নয়, LibreOffice-ই বন্ধ হবে।

অবশ্যই। এবার **LibreOffice Calc-এর Edit Menu** একদম সহজভাবে শিখি।

# ✏️ Edit Menu — কী কাজে লাগে?

**Edit Menu** মূলত spreadsheet-এর data **কাটা, copy, paste, undo, search, replace, select** ইত্যাদি করার জন্য।

---

## 1. ↩️ Undo

**Edit → Undo**

আপনি যে কাজটি সর্বশেষ করেছেন সেটা বাতিল করবে।

Shortcut:

```text
Ctrl + Z
```

### উদাহরণ

ধরুন A2-তে লিখলেন:

```text
Laptop
```

ভুল হয়েছে। `Ctrl + Z` চাপলে Laptop লেখাটা undo হবে।

আরেকবার `Ctrl + Z` দিলে তার আগের কাজও undo হবে।

---

# 2. ↪️ Redo

Undo করার পর আবার সেই কাজ ফিরিয়ে আনতে:

```text
Ctrl + Y
```

উদাহরণ:

```text
লিখলাম → Undo → Redo
```

অর্থাৎ:

**Undo করা কাজ আবার ফিরিয়ে আনে।**

---

# 3. ✂️ Cut

**Edit → Cut**

কোনো cell-এর data এক জায়গা থেকে সরিয়ে অন্য জায়গায় নিতে।

Shortcut:

```text
Ctrl + X
```

### উদাহরণ

A2:

```text
Laptop
```

A2 select → `Ctrl + X`

তারপর B2 → `Ctrl + V`

তাহলে Laptop A2 থেকে B2-তে চলে যাবে।

**Cut = Move**

---

# 4. 📋 Copy

**Edit → Copy**

একই data-এর duplicate তৈরি করতে।

Shortcut:

```text
Ctrl + C
```

উদাহরণ:

A2:

```text
Laptop
```

A2 copy করে B2-তে paste করলে:

```text
A2 = Laptop
B2 = Laptop
```

দুটো জায়গাতেই থাকবে।

**Copy = Duplicate**

---

# 5. 📌 Paste

**Edit → Paste**

Copy অথবা Cut করা data অন্য জায়গায় বসাতে।

Shortcut:

```text
Ctrl + V
```

যেমন:

```text
A2 → Ctrl+C
B2 → Ctrl+V
```

---

# 6. Paste Special ⭐

এটা একটু advanced কিন্তু খুব গুরুত্বপূর্ণ।

Shortcut:

```text
Ctrl + Shift + V
```

ধরুন A1-এ আছে:

```text
=SUM(B2:B10)
```

আপনি শুধু **result/value** অন্য জায়গায় নিতে চান, formula নিতে চান না।

তাহলে:

**Copy → Paste Special → Values**

এতে formula নয়, শুধু result paste হবে।

### Paste Special দিয়ে আরও করা যায়:

* শুধু Values
* শুধু Formula
* শুধু Formatting
* সবকিছু
* Transpose

---

# 7. Select All

পুরো spreadsheet-এর data/select করতে।

Shortcut:

```text
Ctrl + A
```

একবার/প্রেক্ষিতভেদে current data region, আবার ব্যবহার করলে আরও বড় selection হতে পারে।

Calc-এ পুরো sheet select করার জন্য grid-এর **উপরের-বাম corner**-এর ছোট square-এ click করাও যায়।

---

# 8. Find

কোনো word বা number খুঁজতে।

Shortcut:

```text
Ctrl + F
```

ধরুন আপনার Sheet-এ 500টা product আছে।

আপনি `Laptop` খুঁজছেন।

```text
Ctrl + F
```

তারপর:

```text
Laptop
```

লিখলে Calc সেটা খুঁজে দেবে।

---

# 9. Find Next

একই word একাধিক জায়গায় থাকলে পরের occurrence খুঁজবে।

যেমন:

```text
Laptop
Samsung
Laptop
Apple
Laptop
```

`Laptop` search করলে Find Next দিয়ে একটার পর একটা Laptop পাওয়া যাবে।

---

# 10. Find and Replace ⭐⭐⭐

এটা খুব useful।

Shortcut:

```text
Ctrl + H
```

ধরুন পুরো spreadsheet-এ:

```text
Dhaka
```

আছে।

আপনি সব জায়গায় `Dhaka` পরিবর্তন করে:

```text
Chattogram
```

করতে চান।

Find:

```text
Dhaka
```

Replace:

```text
Chattogram
```

তারপর **Replace All**।

সব matching জায়গা পরিবর্তন হয়ে যাবে।

### ⚠️ সাবধান

**Replace All** দেওয়ার আগে কী পরিবর্তন হচ্ছে দেখে নিন। ভুল word দিলে অনেক cell একসাথে পরিবর্তন হয়ে যেতে পারে।

---

# 11. Track Changes

Document-এ কী কী পরিবর্তন হয়েছে সেটা track করার জন্য।

এটা সাধারণ spreadsheet কাজের সময় খুব বেশি প্রয়োজন হয় না।

---

# 12. Hyperlink

কোনো cell-এর সাথে website/file/link যুক্ত করতে ব্যবহার করা যায়।

উদাহরণ:

Cell:

```text
Open Website
```

এটার সাথে কোনো website link attach করলে click করে website খোলা যাবে।

---


```text
A2 → B2
     ↑
দুই জায়গাতেই data
```

পরেরটা **View Menu**—সেখানে Zoom, Formula Bar, Sidebar, Freeze Rows/Columns-এর মতো জিনিস আছে।

# 1. Normal View

এটাই Calc-এর সাধারণ working view।

```text
     A       B       C       D

```

সেটাই Normal view।

**কখন ব্যবহার করবেন?**
প্রায় সব সাধারণ spreadsheet কাজের সময়।

---

# 2. View Layout / Page Break ধরনের View

কিছু version-এ print/page-related view option থাকতে পারে।

এগুলো দিয়ে spreadsheet-টা **print করলে page-এ কীভাবে ভাগ হবে** সেটা দেখতে সুবিধা হয়।

বিশেষ করে বড় report বানানোর সময় useful।

---

# 3. Show Formula ⭐

এটা খুব গুরুত্বপূর্ণ।

সাধারণভাবে cell-এ formula থাকলে আপনি result দেখেন।

যেমন:

```text
=SUM(B2:B6)
```

Cell-এ দেখা যাচ্ছে:

```text
463000
```

**View → Show Formula** চালু করলে formula দেখা যাবে:

```text
=SUM(B2:B6)
```

অর্থাৎ:

**Show Formula OFF → Result**

**Show Formula ON → Formula**

### Shortcut

Calc version অনুযায়ী shortcut থাকতে পারে:

```text
Ctrl + `
```

তবে menu থেকে চালু করাই beginner-এর জন্য সহজ।

---

# 4. Freeze Rows and Columns ⭐⭐⭐

এটা spreadsheet-এর খুব গুরুত্বপূর্ণ feature।

ধরুন আপনার 1000 rows-এর data আছে।

উপরে:

```text
A          B          C
Product    Price      Stock
```

আপনি নিচে scroll করলে header চলে যাবে।

তখন কোন column কী সেটা বোঝা কঠিন।

**Freeze** করলে header screen-এর উপরে স্থির থাকবে।

---

## উদাহরণ

```text
Product | Price | Stock
Laptop  | 40000 | 10
Mouse   | 1000  | 50
...
```

নিচে অনেক দূর scroll করলেও:

```text
Product | Price | Stock  ← থাকবে
-------------------------
...
...
...
```

### কীভাবে?

যে row/column পর্যন্ত freeze করতে চান, সেই অনুযায়ী cell select করে:

**View → Freeze Rows and Columns**

ব্যবহার করবেন।

Beginner হিসেবে এগুলো আগে ভালোভাবে শেখো:

| Option                      | কাজ                                         |
| --------------------------- | ------------------------------------------- |
| **Cells**                   | Number, Font, Alignment, Border, Background |
| **Rows**                    | Row height, hide/show                       |
| **Columns**                 | Column width, hide/show                     |
| **Merge Cells**             | কয়েকটি cell এক করা                          |
| **Conditional**             | Condition অনুযায়ী automatic formatting      |
| **Styles**                  | একই formatting বারবার ব্যবহার               |
| **Clear Direct Formatting** | দেওয়া formatting remove                     |

### একটি বাস্তব উদাহরণ

ধরো তুমি এই table বানালে:

```text
A1: Product
B1: Price
C1: Quantity
D1: Total
```

Header সুন্দর করতে:

```text
Select A1:D1
        ↓
Format → Cells
        ↓
Font → Bold
        ↓
Alignment → Center
        ↓
Background → Color
        ↓
Borders → All Borders
```

তাহলে তোমার table-এর heading professional-looking হবে।

**পরের menu হিসেবে `Data Menu`** সবচেয়ে গুরুত্বপূর্ণ—এখানে **Sort, Filter, AutoFilter, Pivot Table, Text to Columns, Validity** ইত্যাদি আছে।
অবশ্যই। এবার **LibreOffice Calc-এর Style Menu** সহজভাবে **Menu → Submenu → Submenu** আকারে দেখি।

# 🎨 Style Menu

**Style** মূলত spreadsheet-এর **formatting একসাথে save করে বারবার ব্যবহার** করার জন্য।

যেমন একটি Title-এর জন্য তুমি যদি একবার সেট করো:

* Bold
* Font size 16
* Center
* Background
* Border

তাহলে এগুলো একসাথে একটি **Style** হিসেবে রেখে পরে অন্য cell-এ apply করতে পারবে।

---

## 1. Style → Manage Styles

এটাই Style-এর সবচেয়ে গুরুত্বপূর্ণ option।

**Shortcut:** `F11`

এটি **Styles** sidebar/window খুলে।

সেখানে সাধারণত বিভিন্ন ধরনের Style দেখা যায়:

```text
Style
└── Manage Styles
    ├── Cell Styles
    ├── Page Styles
    └── অন্যান্য style categories
```

### Cell Styles

Cell-এর appearance নিয়ন্ত্রণ করে।

উদাহরণ:

```text
Title
Heading
Good
Bad
Neutral
Warning
```

Version অনুযায়ী built-in style-এর নাম আলাদা হতে পারে।

---

# 2. Cell Style Apply করা

ধরো:

```text
A1 = Sales Report
```

A1 select করে:

```text
Style → Manage Styles
        ↓
Cell Styles
        ↓
একটি Style নির্বাচন
```

করলে সেই Style A1-এ apply হবে।

---

# 3. New Style তৈরি করা

নিজের প্রয়োজন অনুযায়ী Style বানাতে পারো।

ধরো তুমি একটি **My Header** Style বানাতে চাও।

প্রথমে একটি cell select করো।

তারপর Style sidebar-এ:

```text
Cell Styles
   ↓
Right Click
   ↓
New
```

তারপর Style-এর নাম দাও:

```text
My Header
```

এরপর formatting সেট করতে পারো:

```text
Font
Alignment
Borders
Background
Number Format
Protection
```

তারপর **Apply/OK**।

এখন `My Header` Style ভবিষ্যতে আবার ব্যবহার করা যাবে।

---

# 4. Modify Style

আগে তৈরি করা Style পরিবর্তন করতে:

```text
Style
 → Manage Styles
 → Cell Styles
 → My Header
 → Right Click
 → Edit/Modify
```

ধরো আগে Header ছিল:

```text
Bold + Center
```

এখন তুমি Background যোগ করলে, সেই Style যেখানে যেখানে apply করা আছে সেখানেও পরিবর্তন দেখা যেতে পারে।

এটাই Style ব্যবহারের বড় সুবিধা।

---

# 5. New Style from Selection

এটি খুব useful।

ধরো A1 cell-কে তুমি নিজের মতো করে সাজিয়েছ:

```text
Bold
Font Size 14
Center
Border
Background
```

এখন এই formatting-টা Style হিসেবে save করতে চাও।

তাহলে:

```text
Select A1
   ↓
Style
   ↓
New Style from Selection
```

তারপর নাম দাও:

```text
My Header
```

এখন একই formatting অন্য cell-এ সহজে apply করা যাবে।

---

# 6. Load Styles

অন্য কোনো LibreOffice document থেকে Style আনার জন্য ব্যবহার করা যায়।

ধারণাটা হলো:

```text
Document A
   ↓
Styles
   ↓
Document B
```

অর্থাৎ একটি document-এর তৈরি করা Style অন্য document-এ ব্যবহার করতে পারো।

---

# 7. Clear Direct Formatting

Style-এর সঙ্গে এটি একটু গুরুত্বপূর্ণ।

ধরো কোনো cell-এ তুমি manually formatting দিয়েছ:

```text
Bold
Font Color
Background
Border
```

এগুলো remove করতে:

```text
Style → Clear Direct Formatting
```

**Shortcut:** `Ctrl + M`

# 📑 Sheet Menu

সাধারণভাবে:

```text
Sheet
├── Insert Sheet
├── Delete Sheet
├── Rename Sheet
├── Move or Copy Sheet
├── Show Sheet
├── Hide Sheet
├── Navigate
├── Sheet Right-to-Left
├── Show/Hide Grid Lines
└── অন্যান্য sheet options
```

---

## 1. Sheet → Insert Sheet

নতুন worksheet তৈরি করার জন্য।

```text
Sheet
└── Insert Sheet
```

উদাহরণ:

```text
Sheet1
Sheet2
```

এর মধ্যে নতুন sheet যোগ করতে পারো।

নতুন sheet-এর নাম দিতে পারো:

```text
Products
Sales
Report
```

### Shortcut

`Shift + F11` দিয়ে নতুন sheet insert করা যায়।

---

# 2. Sheet → Delete Sheet

বর্তমান worksheet মুছে ফেলার জন্য।

```text
Sheet
└── Delete Sheet
```

যেমন:

```text
Sheet1
Sheet2
Sheet3
```

এর মধ্যে `Sheet3` দরকার না হলে Delete Sheet দিয়ে মুছে দিতে পারো।

⚠️ Sheet-এর গুরুত্বপূর্ণ data থাকলে delete করার আগে সাবধান হবে।

---

# 3. Sheet → Rename Sheet

Sheet-এর নাম পরিবর্তন করার জন্য।

```text
Sheet
└── Rename Sheet
```

যেমন:

```text
Sheet1
```

থেকে:

```text
Sales
```

করতে পারো।

আরও ভালো নাম:

```text
Products
Sales
Expenses
Report
```

এতে formula বুঝতে সহজ হয়।

উদাহরণ:

```text
=SUM(Sales.D2:D100)
```

`Sheet2`-এর চেয়ে `Sales` অনেক বেশি পরিষ্কার।

---

# 4. Sheet → Move or Copy Sheet

একটি sheet অন্য জায়গায় **move** অথবা **copy** করার জন্য।

```text
Sheet
└── Move or Copy Sheet
```

ধরো:

```text
Products
Sales
Report
```

তুমি `Report` sheet-কে `Sales`-এর আগে নিতে চাও।

তাহলে Move ব্যবহার করতে পারো।

### Copy করলে

একই sheet-এর duplicate তৈরি হবে।

```text
Sales
   ↓ Copy
Sales_2
```

---

# 5. Sheet → Show Sheet

আগে Hide করা sheet আবার দেখানোর জন্য।

```text
Sheet
└── Show Sheet
```

ধরো:

```text
Products
Sales
Report
```

`Products` sheet Hide করা হলো।

তখন সেটা দেখা যাবে না।

পরে:

```text
Sheet → Show Sheet
```

দিয়ে আবার দেখাতে পারো।

---

# 6. Sheet → Hide Sheet

বর্তমান sheet সাময়িকভাবে লুকানোর জন্য।

```text
Sheet
└── Hide Sheet
```

উদাহরণ:

```text
Products
Sales
Report
```

তুমি `Products` sheet hide করলে নিচের tabs-এ আর দেখা যাবে না।

**Important:** Hide করা মানে Delete করা নয়। Data এখনও sheet-এর মধ্যে থাকে।

---

# 7. Sheet → Navigate

অনেকগুলো sheet থাকলে sheet-এর মধ্যে দ্রুত move করার কাজে ব্যবহার করা যায়।

উদাহরণ:

```text
Products
Sales
Expenses
Customers
Report
Summary
```

অনেক sheet হলে নির্দিষ্ট sheet-এ দ্রুত যেতে navigation সুবিধা কাজে লাগে।

---

# 8. Sheet → Sheet Right-to-Left

Sheet-এর display direction পরিবর্তনের জন্য।

সাধারণ spreadsheet:

```text
A → B → C → D
```

Right-to-left layout ব্যবহার করলে direction উল্টোভাবে দেখানো যেতে পারে।

এটি বিশেষ layout/language-এর ক্ষেত্রে কাজে লাগতে পারে।

---

# 9. Sheet-এর Tab থেকে আরও Options

নিচের sheet tab-এর ওপর **Right Click** করলেও অনেক গুরুত্বপূর্ণ option পাওয়া যায়।

যেমন:

```text
Sheet1  ← Right Click
   ↓
├── Insert Sheet
├── Delete Sheet
├── Rename Sheet
├── Move or Copy Sheet
├── Select Sheets
├── Show Sheet
└── Hide Sheet
```

অর্থাৎ সবসময় Sheet menu-তে যেতে হবে এমন নয়।

# ⭐ সবচেয়ে গুরুত্বপূর্ণ ৫টি

Beginner হিসেবে এগুলো আগে ভালোভাবে শেখো:

| Option                 | কাজ                          |
| ---------------------- | ---------------------------- |
| **Insert Sheet**       | নতুন worksheet তৈরি          |
| **Delete Sheet**       | worksheet মুছে ফেলা          |
| **Rename Sheet**       | sheet-এর নাম পরিবর্তন        |
| **Move or Copy Sheet** | sheet সরানো বা duplicate করা |
| **Hide/Show Sheet**    | sheet লুকানো/দেখানো          |

### একটি বাস্তব workbook

```text
📗 My Business.ods

├── Products
├── Sales
├── Expenses
├── Customers
└── Report
```

এভাবে আলাদা আলাদা কাজের জন্য sheet রাখলে পরে formula ব্যবহার করাও সহজ হয়।

যেমন Report sheet-এ:

```text
=SUM(Sales.D2:D100)
```

এখানে `Sales` হলো sheet-এর নাম এবং `D2:D100` হলো সেই sheet-এর range।
অবশ্যই। এবার **LibreOffice Calc-এর Data Menu** দেখি। এটা খুব গুরুত্বপূর্ণ, কারণ **Sort, Filter, Pivot Table, Data Validation, Text to Columns**—এসব এখানেই থাকে।

> LibreOffice-এর version অনুযায়ী কিছু option-এর নাম বা অবস্থান সামান্য পরিবর্তিত হতে পারে।

# 📊 Data Menu

সাধারণভাবে Data Menu-তে এমন options থাকে:

```text
Data
├── Sort
├── AutoFilter
├── More Filters
│   ├── Standard Filter
│   ├── Advanced Filter
│   └── Reset Filter
├── Pivot Table
├── Subtotals
├── Validity
├── Text to Columns
├── Calculate
├── Group and Outline
└── Statistics
```

---

# 1. Data → Sort

Data-কে **ascending/descending order**-এ সাজানোর জন্য।

ধরো:

```text
Product     Price
Laptop      40000
Mouse       1000
Keyboard    2000
```

Price অনুযায়ী ছোট থেকে বড়:

```text
Mouse       1000
Keyboard    2000
Laptop      40000
```

### Sort-এর সাধারণ options

```text
Data
└── Sort
    ├── Sort Key 1
    ├── Sort Key 2
    ├── Sort Key 3
    └── Options
```

তুমি একাধিক column দিয়েও sort করতে পারো।

উদাহরণ:

```text
1st → Department
2nd → Name
3rd → Salary
```

---

# 2. Data → AutoFilter

এটা খুব useful।

প্রথমে table select করে:

```text
Data → AutoFilter
```

করলে column header-এ ছোট dropdown/filter button আসবে।

যেমন:

```text
Product ▼ | Price ▼ | Stock ▼
```

তারপর শুধু:

```text
Price > 10000
```

বা নির্দিষ্ট Product দেখাতে পারো।

---

# 3. Data → More Filters

এখানে আরও advanced filtering options থাকে।

```text
Data
└── More Filters
    ├── Standard Filter
    ├── Advanced Filter
    └── Reset Filter
```

---

## 3.1 Standard Filter

এক বা একাধিক condition দিয়ে data filter করার জন্য।

উদাহরণ:

```text
Price > 10000
AND
Stock > 5
```

অর্থাৎ দুই condition-ই পূরণ করতে হবে।

---

## 3.2 Advanced Filter

আরও complex filtering-এর জন্য।

যেমন:

```text
Price > 10000
OR
Stock < 5
```

বড় dataset-এ কাজে লাগে।

---

## 3.3 Reset Filter

আগের filter সরিয়ে আবার সব data দেখাতে ব্যবহার করা হয়।

---

# 4. Data → Pivot Table

এটা **খুব গুরুত্বপূর্ণ** feature।

অনেক বড় data থেকে summary/report তৈরি করতে ব্যবহার করা হয়।

ধরো Sales data:

```text
Product   Salesperson   Amount
Laptop    Rahim         40000
Mouse     Karim         1000
Laptop    Karim         40000
Mouse     Rahim         2000
```

Pivot Table দিয়ে এমন summary বানানো যায়:

```text
Product    Total Sales
Laptop       80000
Mouse         3000
```

অর্থাৎ raw data → summary report।

---

# 5. Data → Subtotals

Group অনুযায়ী subtotal বের করতে ব্যবহার করা হয়।

ধরো:

```text
Department    Salary
Sales         20000
Sales         25000
HR            30000
HR            35000
```

Subtotal করলে:

```text
Sales → 45000
HR    → 65000
```

এর সঙ্গে Grand Total-ও পাওয়া যেতে পারে।

---

# 6. Data → Validity

এটি **Data Validation** করার জন্য।

খুব useful যখন তুমি চাও user শুধু নির্দিষ্ট ধরনের data input করুক।

উদাহরণ:

```text
Gender → Male / Female / Other
```

অথবা:

```text
Department → Sales / HR / IT
```

তখন cell-এ dropdown তৈরি করা যায়।

ধরো:

```text
A2 ▼
   ├── Sales
   ├── HR
   └── IT
```

ভুল data entry কমানোর জন্য এটি খুব useful।

---

# 7. Data → Text to Columns

একটি cell-এর text আলাদা আলাদা column-এ ভাগ করার জন্য।

ধরো A1-এ:

```text
Rahim,25,Dhaka
```

Text to Columns ব্যবহার করলে:

```text
A        B    C
Rahim    25   Dhaka
```

হতে পারে।

Delimiter হিসেবে ব্যবহার করা যায়:

```text
Comma ,
Semicolon ;
Tab
Space
```

# 3. Tools → Goal Seek

এটা **খুব গুরুত্বপূর্ণ**।

কোনো formula-এর result নির্দিষ্ট value করতে হলে কোন input value লাগবে সেটা বের করে।

### Example

ধরো:

```text id="q9i1hp"
A1 = Quantity
B1 = Price
C1 = A1*B1
```

Price = `500`

তুমি চাও Total = `10,000`

তাহলে Goal Seek বের করবে:

```text id="g6e9ir"
Quantity = 20
```

অর্থাৎ:

```text
20 × 500 = 10,000
```

### Structure

```text id="v2iwzo"
Tools
└── Goal Seek
    ├── Formula Cell
    ├── Target Value
    └── Variable Cell
```

# 5. Tools → Detective

Formula-এর **relationship খুঁজে বের করার** জন্য।

যেমন:


অর্থাৎ C1-এর formula কোন cell থেকে data নিচ্ছে সেটা visually বোঝাতে পারে।

গুরুত্বপূর্ণ অংশ:

```text id="1y4az0"
Detective
├── Trace Precedents
├── Trace Dependents
├── Remove Precedents
├── Remove Dependents
└── Remove All Traces
```

### Trace Precedents

বর্তমান cell-এর formula **কোন cell থেকে data নিচ্ছে** দেখায়।

### Trace Dependents

বর্তমান cell-এর value **কোন কোন formula-তে ব্যবহার হচ্ছে** দেখায়।

বড় spreadsheet-এর formula বুঝতে খুব useful।
