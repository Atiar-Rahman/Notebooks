# Linux (১–১০)

### 1. What is Linux?

**Answer:** Linux is an open-source operating system based on the Unix architecture. It is widely used for servers, cloud computing, and DevOps because it is secure, stable, and highly customizable.

### 2. What is the `pwd` command?

**Answer:** The `pwd` (Print Working Directory) command displays the full path of the current working directory. It helps users know their current location in the file system.

### 3. What is the `ls` command?

**Answer:** The `ls` command lists the files and directories in the current location. Using options like `-l` or `-a` provides more detailed information.

### 4. What is `chmod`?

**Answer:** `chmod` is used to change file or directory permissions. It controls who can read, write, or execute a file.

### 5. What is `chown`?

**Answer:** `chown` changes the owner and group of a file or directory. It is commonly used by system administrators.

### 6. Difference between `cp` and `mv`?

**Answer:** `cp` copies files or directories, while `mv` moves or renames them. Copy keeps the original file, but move transfers it.

### 7. What is a Linux process?

**Answer:** A process is a program that is currently running. Every process has a unique Process ID (PID).

### 8. What is the `grep` command?

**Answer:** `grep` searches for specific text or patterns inside files. It is useful for finding logs or configuration settings.

### 9. What is the root user?

**Answer:** The root user is the administrator of Linux. It has full control over the system and can perform all operations.

### 10. What is a shell?

**Answer:** A shell is a command-line interface that allows users to communicate with the operating system. Bash is the most commonly used Linux shell.

# Networking (১১–২০)

### 11. What is an IP address?

**Answer:** An IP address is a unique identifier assigned to a device on a network. It allows devices to communicate with each other.

### 12. What is DNS?

**Answer:** DNS (Domain Name System) converts domain names like `google.com` into IP addresses so computers can locate websites.

### 13. What is HTTP?

**Answer:** HTTP (HyperText Transfer Protocol) is used to transfer web pages between a browser and a web server. It is not encrypted.

### 14. What is HTTPS?

**Answer:** HTTPS is the secure version of HTTP. It encrypts data using SSL/TLS to protect communication.

### 15. What is SSH?

**Answer:** SSH (Secure Shell) is a secure protocol for remotely accessing and managing servers over a network.

### 16. Difference between TCP and UDP?

**Answer:** TCP is connection-oriented and reliable, ensuring data delivery. UDP is connectionless, faster, but does not guarantee delivery.

### 17. What is a Port?

**Answer:** A port is a communication endpoint used by applications. Different services use different port numbers, such as HTTP (80) and HTTPS (443).

### 18. What is the OSI Model?

**Answer:** The OSI Model is a seven-layer framework that explains how data travels across a network. It helps standardize network communication.

### 19. What is a Router?

**Answer:** A router connects different networks and forwards data packets between them. It helps devices access the internet.

### 20. What is a Firewall?

**Answer:** A firewall is a security system that monitors and controls incoming and outgoing network traffic based on predefined rules.

# Git (২১–২৭)

### 21. What is Git?

**Answer:** Git is a distributed version control system used to track changes in source code. It helps developers collaborate efficiently.

### 22. What is GitHub?

**Answer:** GitHub is a cloud-based platform that hosts Git repositories. It provides collaboration features like pull requests and issue tracking.

### 23. What is `git clone`?

**Answer:** `git clone` copies an existing remote repository to your local computer. It creates a complete local version of the project.

### 24. What is `git commit`?

**Answer:** `git commit` saves staged changes into the local repository. Each commit represents a snapshot of the project.

### 25. What is `git push`?

**Answer:** `git push` uploads local commits to a remote repository such as GitHub. It makes your changes available to others.

### 26. What is `git pull`?

**Answer:** `git pull` downloads the latest changes from the remote repository and merges them into the local repository.

### 27. What is a Branch?

**Answer:** A branch is an independent line of development in Git. It allows developers to work on new features without affecting the main code.

# Docker (২৮–৩৪)

### 29. What is a Docker Container?

**Answer:** A Docker container is a lightweight, isolated environment where an application runs with all its required dependencies.

### 30. What is a Docker Image?

**Answer:** A Docker image is a read-only template used to create containers. It contains the application, libraries, and configurations.

### 31. Difference between VM and Docker?

**Answer:** A Virtual Machine includes a full operating system, while Docker containers share the host operating system kernel, making them lighter and faster.

### 32. What is Docker Hub?

**Answer:** Docker Hub is an online repository where Docker images are stored and shared. Users can download or upload images.

### 33. What is `docker run`?

**Answer:** The `docker run` command creates and starts a new container from a Docker image.

### 34. What is `docker ps`?

**Answer:** `docker ps` displays the list of running Docker containers. Using `docker ps -a` shows all containers.

# 1. What is Networking?

**Answer:**  
Networking is the process of connecting two or more computers or devices to share data, resources, and services. It enables communication between devices over a network.

---

# 2. What is a Network?

**Answer:**  
A network is a group of interconnected computers or devices that communicate and share information using communication protocols.

---

# 3. What is an IP Address?

**Answer:**  
An IP (Internet Protocol) address is a unique numerical address assigned to every device on a network. It allows devices to identify and communicate with each other.

**Example:** `192.168.1.10`

---

# 4. What is IPv4?

**Answer:**  
IPv4 is the fourth version of the Internet Protocol. It uses a **32-bit address** and is written in dotted decimal notation.

**Example:** `192.168.1.1`

---

# 5. What is IPv6?

**Answer:**  
IPv6 is the latest version of the Internet Protocol. It uses **128-bit addresses** and supports a much larger number of devices than IPv4.

---

# 6. What is DNS?

**Answer:**  
DNS (Domain Name System) converts human-readable domain names (like google.com) into IP addresses so computers can locate websites.

---

# 7. What is DHCP?

**Answer:**  
DHCP (Dynamic Host Configuration Protocol) automatically assigns IP addresses and other network settings to devices.

---

# 8. What is Gateway?

**Answer:**  
A gateway is a device that connects one network to another. It allows devices in a local network to communicate with external networks like the Internet.

---

# 9. What is a Router?

**Answer:**  
A router connects different networks and forwards data packets between them. It is commonly used to provide internet access.

---

# 10. What is a Switch?

**Answer:**  
A switch connects devices within the same local network (LAN) and forwards data based on MAC addresses.

---

# 11. Difference between Router and Switch?

**Answer:**  
A switch connects devices within the same network using MAC addresses. A router connects different networks using IP addresses.

---

# 12. What is a Hub?

**Answer:**  
A hub connects multiple devices but sends data to all connected devices without checking the destination.

---

# 13. What is MAC Address?

**Answer:**  
A MAC (Media Access Control) address is a unique hardware address assigned to a network interface card (NIC).

**Example:** `00:1A:2B:3C:4D:5E`

---

# 14. What is a Port?

**Answer:**  
A port is a logical communication endpoint used by applications to send and receive data.

---

# 15. What is HTTP?

**Answer:**  
HTTP (HyperText Transfer Protocol) is used to transfer web pages between a browser and a web server.

**Port:** **80**

---

# 16. What is HTTPS?

**Answer:**  
HTTPS is the secure version of HTTP. It encrypts communication using SSL/TLS.

**Port:** **443**

---

# 17. Difference between HTTP and HTTPS?

**Answer:**

HTTP → Not Secure

HTTPS → Secure (Encrypted)

HTTP uses Port 80, HTTPS uses Port 443.

---

# 18. What is FTP?

**Answer:**  
FTP (File Transfer Protocol) is used to transfer files between computers over a network.

**Port:** **21**

---

# 19. What is SSH?

**Answer:**  
SSH (Secure Shell) is a secure protocol used to remotely access and manage Linux servers.

**Port:** **22**

---

# 20. What is Telnet?

**Answer:**  
Telnet is a remote login protocol that sends data without encryption. SSH is preferred because it is secure.

**Port:** **23**

---

# 21. What is SMTP?

**Answer:**  
SMTP (Simple Mail Transfer Protocol) is used to send emails.

**Port:** **25**

# 1. What is CIDR?

**Answer:**  
CIDR (Classless Inter-Domain Routing) is a method of allocating IP addresses and creating subnetworks more efficiently. It uses a slash notation (e.g., **192.168.1.0/24**) to indicate how many bits are used for the network portion of an IP address.

**Example:**

- `192.168.1.0/24`
    
- Here, **24 bits** represent the network and **8 bits** represent the host.
    

---

# 2. What is a Subnet Mask?

**Answer:**  
A subnet mask is a 32-bit number used to divide an IP address into the **network part** and the **host part**. It helps devices determine whether another device is on the same network or a different network.

**Example:**

- IP Address: `192.168.1.10`
    
- Subnet Mask: `255.255.255.0`
    

---

# 3. Difference between Public IP and Private IP?

|Public IP|Private IP|
|---|---|
|Used on the Internet|Used inside a local network|
|Globally unique|Not globally unique|
|Assigned by ISP|Assigned by Router/DHCP|
|Accessible from anywhere|Not directly accessible from the Internet|

**Answer:**  
A **Public IP** is assigned by an ISP and is reachable over the Internet. A **Private IP** is used within local networks (LAN) and cannot be accessed directly from the Internet.

**Private IP Ranges**

- `10.0.0.0 – 10.255.255.255`
    
- `172.16.0.0 – 172.31.255.255`
    
- `192.168.0.0 – 192.168.255.255`
    

---

# 4. What is NAT?

**Answer:**  
NAT (Network Address Translation) is a networking technique that converts **private IP addresses** into a **public IP address**. It allows multiple devices in a private network to share a single public IP when accessing the Internet.

**Example:**  
If 10 computers use one internet connection, NAT enables all of them to communicate through a single public IP.

---

# 5. Difference between LAN, MAN, and WAN?

|LAN|MAN|WAN|
|---|---|---|
|Local Area Network|Metropolitan Area Network|Wide Area Network|
|Small area|City-wide|Country/World-wide|
|Fast|Medium|Slower than LAN|
|Example: Office|Example: City Network|Example: Internet|

**Answer:**

- **LAN** connects devices within a small area such as a home, office, or school.
    
- **MAN** connects multiple LANs across a city or metropolitan area.
    
- **WAN** connects networks over large geographical areas, such as countries or continents. The Internet is the largest WAN.
    

---

# 6. What is Load Balancing?

**Answer:**  
Load Balancing is the process of distributing incoming network traffic across multiple servers. This improves application performance, increases availability, and prevents any single server from becoming overloaded.

**Example:**  
If **1,000 users** visit a website simultaneously, a load balancer distributes the requests among several servers instead of sending all traffic to one server.

---

# 7. Difference between Static IP and Dynamic IP?

**Answer:**  
A **Static IP** remains fixed and does not change, making it suitable for servers and hosting services. A **Dynamic IP** is assigned automatically by DHCP and may change over time, making it suitable for client devices.

---

# 8. What is DHCP?

**Answer:**  
DHCP (Dynamic Host Configuration Protocol) automatically assigns IP addresses, subnet masks, default gateways, and DNS server addresses to devices on a network. This eliminates the need for manual IP configuration.

---

# 9. What is a Default Gateway?

**Answer:**  
A Default Gateway is the router or device that forwards traffic from a local network to other networks, such as the Internet. It acts as the exit point for data leaving the local network.

---

# 10. Difference between IPv4 and IPv6?

|IPv4|IPv6|
|---|---|
|32-bit|128-bit|
|Limited addresses|Very large address space|
|Example: 192.168.1.1|Example: 2001:db8::1|

**Answer:**  
IPv4 uses **32-bit** addresses and supports about **4.3 billion** unique addresses. IPv6 uses **128-bit** addresses, providing a vastly larger address space and solving IPv4 address exhaustion.

# ⭐ Most Important Interview Questions (BJIT)

### Q1. Why is HTTPS more secure than HTTP?

**Answer:** HTTPS encrypts data using SSL/TLS, while HTTP sends data in plain text. This protects information from interception and tampering.

### Q2. Why do we use SSH instead of Telnet?

**Answer:** SSH encrypts all communication, making it secure for remote server access. Telnet sends data in plain text, making it vulnerable to attacks.

### Q3. Why is DNS important?

**Answer:** DNS allows users to access websites using domain names instead of remembering numerical IP addresses, making Internet usage much easier.

### Q4. Why is Load Balancing important in Cloud Computing?

**Answer:** It distributes traffic across multiple servers, improving performance, scalability, fault tolerance, and ensuring high availability.

### Q5. What is the role of a Router?

**Answer:** A router connects different networks and forwards packets based on IP addresses, enabling communication between local networks and the Internet.
