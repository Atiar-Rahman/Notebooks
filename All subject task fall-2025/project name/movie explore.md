## Movie Explore

A responsive movie and TV-show discovery application build with react. Browse the catalogue, search by title and open a show card to view it details.

> Move Explore uses the public [TVmaze API](https://www.tvmaze.com/api/)  for it catalouge data

# features
- browse a collection of shows in a responsive card grid
- search shows by title
- open a details modal with poster, overview, rating, premiere date, genres, language, runtime, type, status, network and country.
- loading skeletons while catalouge data is being fetched
- a retry interfece when an api request fails.
- responsive desktop and mobile navigation.
- custom 404page for unknown routes
- dark, move focused interface built with tailwind css and daysui.
