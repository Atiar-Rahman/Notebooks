---
হ্যাঁ—**এটাই তোমার এখন সবচেয়ে বেশি শেখা দরকার।** শুধু design দেখা যথেষ্ট না; **কেন এমন design করেছে সেটা চিন্তা করতে শেখা** দরকার।

ধরো ThemeForest-এ একটা dashboard দেখলে, সরাসরি copy না করে নিজেকে এই প্রশ্নগুলো করবে:

### 🧠 ১. “কেন এখানে এটা রাখা হয়েছে?”

যেমন Sidebar বাম পাশে কেন?

→ কারণ navigation সবসময় সহজে access করা দরকার।

### 🧠 ২. “User প্রথমে কী দেখবে?”

Dashboard খুললে:

**Total Users → Revenue → Recent Orders → Chart**

কেন এই order?

→ গুরুত্বপূর্ণ information আগে দেখানোর জন্য।

### 🧠 ৩. “এখানে কোন সমস্যা solve করছে?”

ধরো একটা **Search box** আছে।

নিজেকে বলবে:

> User যদি ৫০০টা student-এর মধ্যে একজনকে খুঁজতে চায়, কীভাবে দ্রুত খুঁজবে?

তখন বুঝবে Search দরকার।

### 🧠 ৪. “আমি হলে কী পরিবর্তন করতাম?”

এটাই সবচেয়ে গুরুত্বপূর্ণ।

একটা design দেখে বলবে:

> “এই table-এ ১০টা column দিলে crowded হবে। আমি ৫টা রাখব এবং Details page-এ বাকি information দেখাব।”

এভাবে **নিজের decision নেওয়ার ক্ষমতা** তৈরি হবে।

## 🔥 একটা Design Thinking Formula মনে রাখো

যেকোনো application দেখলে:

**User → Problem → Information → Action → Layout**

উদাহরণ: **Student Management**

**User:** Teacher/Admin  
↓  
**Problem:** অনেক student manage করতে হবে  
↓  
**Information:** Name, ID, Department, Status  
↓  
**Action:** Search, Add, Edit, Delete  
↓  
**Layout:** Sidebar + Dashboard + Student Table + Form

এখন তুমি আর শুধু “সুন্দর design” দেখছ না—**design কেন এমন হয়েছে সেটা বুঝছ।**

### প্রতিদিন ১টা UI নিয়ে এই ৫টা প্রশ্ন করো:

```text
1. এটা কার জন্য?
2. User এখানে কী করতে এসেছে?
3. সবচেয়ে গুরুত্বপূর্ণ information কোনটা?
4. User-এর next action কী?
5. আমি হলে কী পরিবর্তন করতাম?
```

**৩০ দিন এভাবে practice করলে তোমার “design sense” এবং চিন্তা করার ক্ষমতা দুটোই অনেক improve করবে।**

আর তোমার confidence-এর জন্য সবচেয়ে গুরুত্বপূর্ণ বিষয় হলো—**প্রথমে নিজের মাথা থেকে perfect design বের করার চেষ্টা করবে না। Reference দেখে reasoning করবে, তারপর decision নেবে।**
