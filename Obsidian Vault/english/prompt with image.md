অবশ্যই। তুমি চাইছো এমন **একটা reusable prompt**, যেখানে শুধু **image + prompt** দিলেই প্রতিবার একই structured output পাবে—যাতে **English speaking, presentation, vocabulary, parts of speech এবং word derivatives** সব একসাথে practice করা যায়।

নিচের prompt-টা কপি করে ব্যবহার করতে পারো:

```text

I am learning English speaking and presentation skills using images.

Analyze the uploaded image and create a complete English learning practice set based ONLY on what can reasonably be seen in the image.

Follow this exact structure:

# 1. IMAGE OVERVIEW
Give:
- What the image shows
- Type of place/scene
- Overall atmosphere
- Main objects/people
Use simple English.

# 2. 20 SIMPLE SENTENCES
Create 20 natural English sentences describing the image.
- Beginner-friendly
- Useful for spoken English
- Avoid unnecessary difficult vocabulary
- Do not repeat the same sentence pattern too much

# 3. 10 PRESENTATION SENTENCES
Create 10 slightly more advanced sentences that I can use in a 1–2 minute presentation about the image.

# 4. VOCABULARY TABLE

Extract 25 important and useful words from the image.

Use this table:

| # | Word | বাংলা অর্থ | Parts of Speech | Synonym | Antonym | Example Sentence |
|---|------|------------|-----------------|---------|---------|------------------|

Rules:
- Include useful words for spoken English and presentation.
- Give the most appropriate Bengali meaning for the image/context.
- Identify the correct part of speech.
- Give 2–3 common and useful synonyms where possible.
- Give 1–3 natural antonyms where possible.
- If a natural synonym or antonym does not exist, write "—".
- Do not invent synonyms or antonyms.
- Prefer common everyday English over rare/academic words.
- Make sure synonyms and antonyms match the same part of speech whenever possible.
- Provide one natural example sentence for every word.

# 5. WORD FAMILY / DERIVATIVES
For the most useful words, show their word families.

Use this table:

| # | Base Word | Noun | Verb | Adjective | Adverb | বাংলা মূল অর্থ |
|---|-----------|------|------|-----------|--------|----------------|

Rules:
- Give only real and commonly used derivatives.
- If a form does not naturally exist, use "—".
- Do NOT invent uncommon or incorrect derivatives.
- Include around 15–20 useful word families.

# 6. USEFUL PHRASES
Give 15 useful phrases for describing images and giving presentations.

Use this table:

| # | English Phrase | বাংলা অর্থ | Example |
|---|----------------|------------|---------|

# 7. PRESENTATION STRUCTURE
Create a complete 1–2 minute presentation about the image using:

Opening
→ Introduction
→ Description
→ Main Details
→ Personal Observation
→ Conclusion

Keep the English natural and easy to speak.

# 8. SPEAKING PRACTICE
Give me 5 questions about the image that I can answer orally.

Questions should gradually become harder:
Question 1–2 = Easy
Question 3 = Medium
Question 4–5 = Advanced

# 9. CHALLENGE
Give me one task:

"Look at the image and speak for 2 minutes without reading."

Give me 8–10 keywords that I can use as hints instead of a full script.

# 10. IMPORTANT GRAMMAR
Identify 5 useful grammar patterns from the example sentences.

For each one, show:
- Grammar pattern
- Example
- বাংলা explanation

# 11. PRONUNCIATION PRACTICE
Select 10 potentially difficult words from the vocabulary.
Give:
- Word
- Simple pronunciation guide
- বাংলা pronunciation

# 12. FINAL PRACTICE PLAN
Give me a short practice routine:

Step 1 → Read vocabulary
Step 2 → Read sentences
Step 3 → Hide the sentences
Step 4 → Describe the image
Step 5 → Give the 2-minute presentation
Step 6 → Record myself
Step 7 → Check mistakes

IMPORTANT RULES:
1. Base everything on the uploaded image.
2. Never identify real people in the image.
3. Do not invent details that cannot reasonably be seen.
4. Keep explanations beginner-friendly.
5. Prioritize spoken English over academic English.
6. Use natural everyday English.
7. Correct grammar and word usage carefully.
8. Avoid unnecessary repetition.
9. Use Markdown tables wherever requested.
10. Always include Bengali meanings.
11. For word derivatives, never invent forms.
12. Make the output clean, organized, and easy to study.
13. Do not ask me follow-up questions; directly generate the complete practice set.
```

### ⭐ কীভাবে ব্যবহার করবে

**① Image upload করবে**  
**② এই prompt paste করবে**

**Image Description → 20 Sentences → Vocabulary → Parts of Speech → Word Families → Phrases → Presentation → Speaking Questions → Grammar → Pronunciation → Practice Plan**
