### সবচেয়ে গুরুত্বপূর্ণ learning method

প্রতিটি package-এর জন্য এই 5-step follow করো:

**1. Why →** package কেন ব্যবহার করা হয়  
**2. Installation →** কীভাবে install করতে হয়  
**3. Core API →** 10–15টা গুরুত্বপূর্ণ function/class  
**4. Mini Project →** package দিয়ে ছোট project  
**5. Real Project →** নিজের বড় project-এ ব্যবহার

উদাহরণ:

**Requests**  
→ GET request  
→ POST request  
→ headers  
→ parameters  
→ JSON  
→ authentication  
→ error handling  
→ তারপর **API client project**
