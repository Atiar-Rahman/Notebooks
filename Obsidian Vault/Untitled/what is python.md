**Python** is a **high-level, general-purpose programming language** known for being easy to read and write.

It is widely used in:

- 🌐 **Web development** — Django, Flask, FastAPI
    
- 🤖 **AI & Machine Learning** — PyTorch, TensorFlow, scikit-learn
    
- 📊 **Data Science** — NumPy, Pandas, Matplotlib
    
- 🔐 **Cybersecurity** — automation, network analysis, security scripting
    
- ⚙️ **Automation** — file handling, web automation, system tasks
    
- 🖥️ **Desktop applications**
    
- 🧪 **Scientific computing**
    
- 🔌 **Backend/API development**
    

### Simple example

```python
name = "Ati"

print("Hello", name)
```

Output:

```text
Hello Ati
```

### Why is Python popular?

Python has very simple syntax compared with many languages:

```python
if age >= 18:
    print("Adult")
else:
    print("Minor")
```

You don't need lots of symbols like `{ }` or `;`, which makes it beginner-friendly.
