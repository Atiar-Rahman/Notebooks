# Chapter 1: Algorithm কী?

**Definition**

Algorithm হলো একটি **Step-by-Step নির্দেশনা**, যা কোনো নির্দিষ্ট সমস্যা সমাধান করতে ব্যবহৃত হয়।

সহজ ভাষায়,

> **Problem + Steps = Algorithm**

---

## উদাহরণ ১

**Problem**

১০ এবং ২০ যোগ করো।

Algorithm

Step 1 → প্রথম সংখ্যা নাও

Step 2 → দ্বিতীয় সংখ্যা নাও

Step 3 → দুইটি যোগ করো

Step 4 → ফলাফল দেখাও

Output

```
30
```

---

## Python

```python
a = 10
b = 20

print(a + b)
```

# Chapter 1: Complexity কী?

# Chapter 2: Time Complexity কী?

Time Complexity কোনো Algorithm-এর **Input বড় হলে তার Running Time কীভাবে বাড়ে**, তা প্রকাশ করে।

এটি **Actual seconds** নয়।

উদাহরণ:

ধরি,

```
N = 10
```

১০টি কাজ করতে ১০ ধাপ লাগবে।

```
N = 1000
```

১০০০টি কাজ করতে ১০০০ ধাপ লাগবে।

এটাই হলো **O(n)**।

---

## Example

```python
for i in range(n):
    print(i)
```

Loop টি n বার চলবে।

Time Complexity

```
O(n)
```

# Cheat Sheet

```
O(1)       → Constant

O(log n)   → Binary Search

O(n)       → Single Loop

O(n log n) → Merge Sort

O(n²)      → Nested Loop

O(n³)      → Triple Loop

O(2ⁿ)      → Recursive Fibonacci

O(n!)      → Permutations
```
